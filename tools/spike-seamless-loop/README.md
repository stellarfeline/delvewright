# Spike: a seamless relative-teleport loop (vanilla 1.21.11)

**Question.** When a body crossing a one-cell slab is moved by a relative `tp` back to an identical earlier section, what does the pinned server do to the body, what is its client told, does a one-tick poll catch every crossing at every speed a body has, and what does a second player standing in the corridor see? The answers feed spec-0086 (`docs/specs/spec-0086-an-endless-corridor.md`), which turns the mechanism into a declared region the compiler proves seamless.

Research tooling only: never shipped, not wired into CI, never read by the compiler. The pack is generated by `gen.py` (deterministic) and committed so it can be copied straight into a world.

## What it measures, and where

`run.sh` boots the pinned server image (`itzg/minecraft-server@sha256:3e7db256…`, `versions.toml [images.base]`, view distance 8) on a flat world (bedrock 1, stone 118, water 8, ocean), installs `dw-loop-spike/`, and `measure.mjs` drives two mineflayer bots (harness pin 4.37.1) — a **mover** and a **witness** — while reading the server's state over rcon through `tools/lib/rcon.mjs`. Every command's reply is read. Raw readings: `observations.json`.

| Reading | How |
|---|---|
| The body's `Pos`, `Motion` and `Rotation` before and after the `tp`, in the same tick | `loop.mcfunction` stores each into a score (×1000, rotation ×100) on either side of the `tp` |
| The one `position` packet the mover's client receives per move: coordinates, deltas, flags | packet capture on the mover |
| The mover's velocity, yaw and pitch the physics tick before the move against the tick of it | `physicsTick` snapshots and `forcedMove` |
| Chunks sent or unloaded around a move, with their distance from the body | `map_chunk` / `unload_chunk` in a window round each move |
| Every crossing caught: walking, sprinting, sprint-jumping with the jump held | `#moves` against crossings; the mover's `z` never past the slab unmoved |
| The fastest tick per locomotion | per-tick displacement, the move itself excluded by its size |
| A falling body against a one-cell and a three-cell slab, ten drops each from `y 310`, and the fall law fitted from one drop's per-tick speeds | the catch slabs tag, never move; `fallLaw` fits `v' = k·(v + g)` and reports its limit |
| The release: a crossing after `#released` is set moves nobody | `#moves` and the forced-move count across the walk |
| What the witness is told about the mover around a move | packet capture on the witness, filtered to the mover's entity id |

What a client **renders** between two frames is not measurable here. Spec-0086 §2 states each reading with its instrument and §10 names what stays unchecked.

## Rerunning

- Edit `gen.py`, then `python3 gen.py`; it rewrites `dw-loop-spike/` wholesale.
- `EULA=TRUE tools/spike-seamless-loop/run.sh [--out <path>]` re-measures (needs `harness/node_modules`; uses an ephemeral port, removes its container on exit).
