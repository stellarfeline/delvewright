# Scene generation & world building — the technique map

**Single map of every approach this project has researched, probed, built,
or rejected for generating scenes and worlds.** One row per approach; every row
states what the approach is for, what it provably cannot do, which pipeline
layer it sits at, its adoption status with the decision's source, whether it was
ever tested and what the test showed, and where it lives in code today. Rejected
and superseded approaches stay listed **with their reasons** — a recorded reason
is what stops a dead end being re-proposed. Sources are cited per claim
(`path:line`, ADR/spec id, or the out-of-repo session record: "task archive
68f4f0ec #N" = `~/.claude/tasks/68f4f0ec-20bc-47f8-a70e-808d8fbe50cc/N.json`,
"session 68f4f0ec" = that session's transcript). A claim that could not be
established says so.

## 1. The capability axis: three tiers

Scene-building capability is judged in **three tiers** (owner escalation,
2026-08-04 — until this document the framing existed only in the session record:
session 68f4f0ec, 2026-08-04; task archive 68f4f0ec #161 `tier_rubric`):

- **Tier 1 — generic serviceable structures.** Houses, walls, corridors,
  interiors that read as "a building". The in-house generators plus their
  weathering passes reach this tier and, per the owner's 2026-08-04 assessment,
  do not exceed it; a candidate technique that only reaches Tier 1 is a
  marginal upgrade.
- **Tier 2 — a specific named referent.** "Temple of Heaven", "ancient Greek
  temple": the output must resemble the *named* thing — semantic fidelity, not
  plausible architecture. This is a **hard requirement**. It is an
  input-modality property: a technique that cannot accept a named/text/image
  reference cannot reach Tier 2 in principle (task archive 68f4f0ec #161,
  dossier finding 3).
- **Tier 3 — atmosphere-tier set-pieces.** Not a building but a *scene* whose
  power is composition: scale contrast, silhouette, lighting, the approach
  framing of a first encounter (reference example: a colossal ruined-bridge
  battlefield). Confirmed unserved by any off-the-shelf tool (task archive
  68f4f0ec #161, dossier finding 8) and by this project's own probe, where the
  missing layer was measured to be **presentation** (lighting / fog / camera /
  approach framing), not the geometry generator
  (`docs/experiments/m3-landmark-sandbox-probe/`).

Current standing, in tier terms: **T1 is the shipped path** (§3 rows 1–4);
**T2 is proven feasible and has an adopted production route** (grammar
programs + curation, §3 row 5; probe evidence §5 row 2); **T3 is unserved,
localized to the render/composition layer, and is M4 design work** (§7).

## 2. Layer vocabulary

The owner's three-layer editing frame (spec-0017): **L1 siting** (place
structures on a macro world — M6, not begun), **L2 massing** (the piece/pool
layout graph of an area), **L3 detailing** (block-level finishing). This map
adds the layers around them:

| Layer | Meaning |
|---|---|
| intent | aligning the human/model on what to build, before geometry exists |
| piece | generating one prefab (a `.nbt` structure + metadata) |
| layout (L2) | assembling placed pieces into an area |
| detail (L3) | block-level finishing of an assembled world |
| surround | the terrain/backdrop context around a scene |
| light | the lighting model of the assembled world |
| review | rendering and judging the result (human or machine) |

## 7. Tier 3: unserved, and what would serve it

No tool — external or in-house — composes an atmosphere-tier set-piece
end-to-end (task archive 68f4f0ec #161 finding 8; probe §5.2 confirmed the gap
empirically and localized it: both bridge builds had every *noun* — arches,
collapse, scale, gold — and the flattening happened in presentation). Standing
decisions and assets:

- **The missing layer is this project's render/composition layer**, not the
  geometry generator: fixed ambient light and a bounding-box-fit orbit camera
  cannot show scale contrast or an approach. The designated route for Tier-3
  *evaluation* is the Chunky free-camera scene path (`delve-render scene`),
  already built (§3.7); what remains unbuilt is composition authoring —
  lighting/fog/framing as declarable, provable scene properties.
- **Ingredients already owned** (dossier finding 8): the compiler's proven
  critical path (approach framing knows where the player will walk) and the
  spec-0010 lighting declarations (§3.10); plus the horizon/backdrop axes of
  spec-0026 (§4.4) once built, and the souls staging vocabulary (§3.5) for
  encounter-shape composition.
- **Division of labor ruling** (session 68f4f0ec, 2026-08-04, planner analysis
  presented to the owner): materials are machine problems; *composition is art
  direction* — human taste, with the machine making iteration cheap
  (auto-rendered player-POV frames against reference stills). Tier-2/Tier-3
  quality is a perceptual property, not a provable one, so the recurring
  toolchain component is a reference-carrying visual review step (rows §3.12,
  §3.13), never a hard gate (rank-only ruling).
- Tier-3 composition is **M4 design work, planner-personal** (task archive
  68f4f0ec #161 strategy D "right ambition, wrong moment"; spec-0027 non-goals
  defer it to M4).
