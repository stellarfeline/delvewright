# `delvewright_dsl::compass`

The reference page for `crates/dsl/src/compass.rs`: the diagnostics-catalog row of every DW code this module declares. The catalog's shared rules are in [`compiler.md` §5](../compiler.md#5-diagnostics-catalog).

## Diagnostics

### DW1049 — a direction names what the player sees (`dsl::compass`; error; exit 1)

The rule is spec-0116; the writing rule it enforces is [`game-writing.md` F1](../game-writing.md#1-two-registers-never-mixed). Raised by `delvec validate` (and every verb that validates first), and states its binding on every run: `compass binding (DW1049): <judged> of <lines> player-facing line(s) judged; <n> declared name(s); <exempt> compass word(s) inside a declared name, <refused> refused`.

| Code | Meaning |
|------|---------|
| `DW1049` | (spec-0116) **A compass point used as a direction in player-facing text.** A line of the English l10n inventory (`dsl::l10n::inventory`, the one walk of every player-facing string) carries a compass word that no declared name covers. **Fields judged**: every `Inventoried` field of `crates/dsl/tests/l10n_surface.rs` `SURFACE` (the classification held exact against the stage schemas `delvec schema --stage all` exports) whose text kind is not a name — 22 of the 36 player-facing fields, of 119 string-valued fields across the seven stage schemas; the other 14 (`Actor.name`, `Area.name`, `Class.name`, `HealthBar.title`, `ItemDrop.name`, `KitItem.name`, `LootItem.name`, `Npc.name`, `Objective.item_name`, `QuestEffect.name`, `Shop.title`, `StateDecl.name`, `WaveMob.name`, `WorldContent.title`) are declared names, never judged. The five map-pipeline schemas of the same export carry 25 string fields (`design` 3, `detail-plan` 1, `geometry-brief` 3, `layout-graph` 5, `site-plan` 13, `dsl_version` counted in each) — notes, seam forms, block ids and kinds — none player-facing. The DSL has no sign or book text. **Compass word**: the visible text is split into words, maximal runs of alphabetic characters; a word is a compass word when, lower-cased, it is `north`, `south`, `east`, `west`, or `northeast`/`northwest`/`southeast`/`southwest`, bare or with the suffix `ern`, `ernmost`, `erly`, `ward` or `wards`; `north-east` is two words, each refused. A word that only contains a cardinal (`Westmarch`, `Northmen`, `eastgate`) is another word. Abbreviations are refused only where unambiguous: `NE`, `NW`, `SE`, `SW` and the eight three-letter points (`NNE` … `NNW`), upper-case and case-sensitive; a single letter is never refused. **Proper-name rule**: a compass word is exempt when it lies inside a run of words equal, ignoring case, to the words of a declared name with its leading `the`/`a`/`an` dropped — an area named `The North Gate` makes `past the north gate` a name. A name is declared by stating it in one of the 14 name fields; there is no other declaration, and nothing is judged by capitalisation. **English only**: every other language is transcreated from the English line and held to it by `DW0187`/`DW0188`, so the direction a line gives is decided in the English, and no per-language word list is held from a cited source. The message names the inventory key (the field path, as `#/<key>`), the line's text kind, the word and the line. Prescription: say where the thing is from the player's own body or from a landmark they can see — `turn around: the first door on your right`, `past the well, the door with the lantern` — or, where the word is part of a place's name, declare that place under the name. |
