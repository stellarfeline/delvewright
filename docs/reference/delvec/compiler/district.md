# `delvec::compiler::district`

The reference page for `crates/delvec/src/compiler/district/mod.rs`: the diagnostics-catalog row of every DW code
this module declares. The catalog's shared rules are in [`compiler.md` §5](../../compiler.md#5-diagnostics-catalog);
the surface they judge — district fragments, the located rule, `--district`, the verbs and the ledger — is
[`compiler.md` §2, *District fragments*](../../compiler.md#district-fragments--districtsx-optional-spec-0103).

## Diagnostics

### DW1004–DW1009 — a delve authored in parallel by district (`compiler::district`; error + advisory)

| Code | Meaning |
|------|---------|
| `DW1004` | **An object a district's fragment carries stands outside its district, or reaches into a sibling** (spec-0103 §7.3). Validation tier (exit 1), `compiler::district::located::check`, bound in the one validation funnel (`cli::campaign::validate_loaded`). One walk over each object as the fragment spells it locates every anchor, place and plan region it names (a boundary seam's gate region and every `region/…` are the whole's); the same walk refuses an id a sibling fragment declares and a flag two fragments both write. The finer rows: a fragment's quest is the plan's quest of the same district; a dialogue tree is referenced only from its own fragment's quests; a station is declared on a place of the district; a detail row's place and a design row's place stem are places of the district; a station on a place the graph does not declare. A cast row that only records where an NPC the quest does not act on stands is not a placement and is not judged. A name the derivation does not provide is `DW0112`'s and this code is not raised on top of it. Every message names the whole's document a crossing object moves to. Asserted per row and per join by `crates/delvec/tests/districts.rs`; the gallery's probes `a-fragment-npc-standing-in-the-hall` and `a-fragment-quest-waiting-on-its-sibling` are refused with it. |
| `DW1005` | **A district fragment carries a field, or a whole document, the whole owns** (spec-0103 §7.2). Validation tier (exit 1), raised by the loader (`compiler::district::fragment::read`) before anything is unioned, so the parse stops on it. A key of a fragment's `content` outside the lists its stage may carry (`state`, `guidance`, `palette`, …), a field of a layout-graph fragment's place other than `id` and `stations`, a design fragment row outside `design/places/<stem>/`, and a `.json` file under `districts/<x>/` that is no fragment kind — each named with the whole's document to move it to. Asserted per shape by `crates/delvec/tests/districts.rs`; the gallery's probes `a-fragment-carrying-state` and `a-fragment-carrying-a-palette` are refused with it. |
| `DW1006` | **Informational: a worker's tree lacks its siblings' quests** (spec-0103 §7.5). A warning (never fails the run), `compiler::district::scope::apply`, printed by `delvec validate --district <x>` only: `<n> planned quest(s) of <m> other district(s) are not expanded in this tree`, with the count of the diagnostics reported beneath it as advisories because they stand only on that absence — `DW0150` naming only siblings' quests, `DW0818` naming one, `DW0172`/`DW0482`/`DW0197` while a sibling quest is unexpanded, `DW0112` on a branch's `leads_to` or naming a sibling's quest, `DW0816`/`DW0817` on the unwritten-mission arm, `DW0181`/`DW0187` on a sidecar row a sibling's unexpanded quest owns — and `DW0460` on another quest's cast about an NPC `x` declares. Without the flag every one of them is judged as a refusal. Asserted by `crates/delvec/tests/districts.rs` and `district_gallery.rs`; the coverage gate prints the gallery's line. |
| `DW1007` | **Advisory: a district outside the partitioning guide's bounds** (spec-0103 §4.2). A warning, `compiler::district::census::advisories`, printed by `delvec district list` beside the row: below the lower bound when no reached place of the district holds a quest beat or a declared station; above the upper bound with more than 12 places or quests in more than one act. It refuses nothing and the verb exits 0: the partition is a creative judgement, and the bounds are the guide's, revised there when a demo level measures them. Asserted by `crates/delvec/tests/districts.rs`; the coverage gate prints the gallery's (its scenery district stands below the lower bound on purpose). |
| `DW1008` | **A path outside a district's write set** (spec-0103 §7.6). `delvec district writes`, exit 1, one per refused path, naming the owner — the whole, or the district whose set holds it. The set is derived from the declaration and the plan: the district's fragments, its places' programs and per-place images, and the piece files `delvec detail` writes for them. Called from exactly two sites: the worker's pre-commit hook (`tools/creator/district-hook.sh`) and the planner's integration gate (`tools/creator/district-integrate.sh`). Asserted by `crates/delvec/tests/districts.rs`. |
| `DW1009` | **`--district` names no district the layout graph declares** (spec-0103 §7.5). `delvec validate --district`, exit 1, raised before anything is judged as that district's tree, listing the declared set. Asserted by `crates/delvec/tests/districts.rs`; the gallery's probe `a-district-flag-naming-nobody` is refused with it. |
