## Diagnostics

### DW046x — the NPC scene ledger (`compiler::cast`; spec-0020)

This module's rows of a section whose prose is on the [`delvec::compiler::cast` page](cast.md#dw046x--the-npc-scene-ledger-compilercast-spec-0020).

| Code | Meaning |
|------|---------|
| `DW0886` | **This place cannot stand on this horizon.** `compiler::seating::check`, bound in the one validation funnel every subcommand goes through (`cli::campaign::validate_loaded`), **validation tier, exit 1**: the verdict is a fact about the documents and the library, so it is reached before a block is placed. Three shapes. *A box under the sea*: on an `ocean` base, a site-plan box whose `floor` puts a body's feet at or below the sea plane (y=62), asked through `seating::feet_under_the_sea(base, world_y)` over the plan's own resolver (`siteplan::placed_boxes`); the remedy is the plan's `floor`, because a box's mass is derived and authored by no one. *An unstated shore*: on an `ocean` base, a piece a place binds authors `minecraft:water` at or below the sea plane — measured from the frame it is placed at, its lowest corner — and declares no `waterline_y`; the move is `DECLARE waterline_y: <n>` with the number the bytes hold, which `DW0887` then holds to them. *Fluid off the world*: on a `void` base, a bound piece whose water reaches its own outer face in some run direction, which `void` puts nothing beyond (`DW0318` refuses the assembled world; this says it from the piece's bytes). A bound piece's declared waterline that the frame does not stand on the sea plane is `DW0344`, asked here at the same tier. Every run prints `seating binding: horizon base `<base>`; site plan: <k> of <n> box(es) judged against this base; <w> bound waterline declaration(s) examined, <s> standing on the sea plane` with the byte-claim binding (`DW0888`) beside it. Moves each taken green in `crates/delvec/tests/remedy_reachability.rs`. |
| `DW0887` | **A declared waterline that is not in the piece's bytes.** `compiler::seating::waterline_reason`, validation tier (exit 1) when a campaign names the piece, and swept over a whole library by `delvec prefab audit <library dir>` from the same implementation. A `waterline_y` is a claim about the bytes — the local y of the piece's top authored `minecraft:water` block — and the check that consumes the field asks only whether `pos.y + waterline_y` equals sea level, never whether there is water at that plane; this code reads the bytes. **Two shapes**: declared with no water anywhere in the piece, and declared over water standing at another plane. **Base-independent by construction**: the fiction is in the library, not in the campaign, so the same document is refused whatever base the world declares. Measured on the shipped content library at the pinned revision: 4 declarations, 4 borne out, 0 refused. That is a green over a library whose fictions were repaired, which is not a green over nothing but is not a proof either, so the property is bound by a PLANTED one — `crates/delvec/tests/seating_cli.rs` writes a `waterline_y` onto a piece that authors no water and checks the sweep refuses it, which holds *a declaration-only implementation reports N of N* against any library at all. **Three doors, one rule.** Validation when a campaign names the piece; `delvec prefab audit <library dir>` over a whole library; and `delvec prefab audit <asset>` at the **admission event**, over one template or one tile-set manifest measured as one assembled building. That last is the door that matters: nothing in any gate hands this command a directory — the admission procedure and the content repository's palette job both walk the pieces one file at a time. Every per-file report carries a `waterline` binding whose `state` is `checked`, `undeclared`, `no-document` (an ingested piece audited before its metadata exists) or `unreadable` (a document nobody can parse is not a document with no waterline) — four facts one silence would conflate. **No generator holds a private copy of this rule** (`prefabs/gallery-generator`'s `assert_the_shore_is_standable` checks only that anchors stand clear of its tide pool): the gallery's shores are proven the way every creator's are. **Prescription**: delete the declaration (a piece that authors no shore has no waterline to state, and deleting it does not make the piece unseatable on an ocean, which seats it by `walk_y`), correct the number to the local y the bytes hold, or author the shore the piece claims. Never answer it by changing the horizon. **Binding**: `waterline audit binding:` states documents read, `.nbt` opened, declarations examined, borne out and refused. |
