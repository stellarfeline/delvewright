# `delvec::compiler::lightning`

The reference page for `crates/delvec/src/compiler/lightning.rs`: the diagnostics-catalog row of every DW code
this module declares. The catalog's shared rules are in [`compiler.md` §5](../../compiler.md#5-diagnostics-catalog).

## Diagnostics

### DW0958–DW0959 — a lightning strike lands where the campaign meant it to (`compiler::lightning`; error; exit 3)

| Code | Meaning |
|------|---------|
| `DW0958` | **A lightning strike's reach holds a place the campaign posts a body** (spec-0092 §5). Build tier (exit 3), `compiler::lightning`, asked over the assembled world beside `DW0899`, after the wave-seating pass, because it reads `DW0511`'s own enumeration (`lethal::posted_places`): the entry spawn, every checkpoint and bonfire seat, every NPC and actor post, every cast placement, every wave seat. While it lives the bolt calls `thunderHit` on every living body whose box meets its own — 3 blocks out on each horizontal axis, 3 below and 9 above its position [cited — `LightningBolt.tick`, read from the pinned bytes] — dealing 5 HP and eight seconds alight, turning a villager into a witch and a pig into a zombified piglin, and charging a creeper. A post is caught when the hitbox the enumeration states, standing at its cell's centre, overlaps that box strictly on every axis (`lightning::in_reach`, the test `AABB.intersects` makes). The message names the strike, the posts and what the bolt does; the remedy is the mark or the post. **Players are not posted and are not proved safe**: a player in reach takes at most 13 HP (`lightning::worst_damage_hp`) and is set alight, a hazard the creator places in plain sight of the beat; a cutscene puts every player in spectator, where the bolt cannot hurt them. |
| `DW0959` | **A lightning strike's struck block is one the game rewrites** (spec-0092 §5). Build tier (exit 3), same module. The struck block is the one under the mark, read from the assembled world; when it is a lightning rod the game powers it, and when it is copper (`lightning::rewrites`, by name: every weathering and waxed copper block of the pinned game carries `copper` in its id) the game scrapes it back along a random walk through the copper beside it — a world write the game rolls, which no proof can state. The message names the block; the remedy is the mark, or a block the bolt leaves alone. Asked before the reach, per strike. |

**Binding.** Every build that assembles a world prints `lightning binding: L strike(s) declared, S struck block(s) read, P post(s) within reach examined, R refused` — zeroes included — before the verdict. A campaign that declares a strike emits `validation/lightning-gate.json` (a row per strike: pointer, mark, cell, struck block; the reach constants), and assembles the world for this proof (`emit::assembles_world`). **Fire is not judged** because a delve has none: the bolt places fire only where `ServerLevel.canSpreadFireAround` holds, which asks whether a non-spectator player stands strictly closer than `fire_spread_radius_around_player`, and setup seals that gamerule at `0` [cited — `LightningBolt.spawnFire`, `ChunkMap.anyPlayerCloseEnoughTo`]; `crates/delvec/tests/v36_lightning.rs` holds the setup to that line.
