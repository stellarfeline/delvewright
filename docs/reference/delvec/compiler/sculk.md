# `delvec::compiler::sculk`

The reference page for `crates/delvec/src/compiler/sculk.rs`: the diagnostics-catalog row of every DW code
this module declares. The catalog's shared rules are in [`compiler.md` §5](../../compiler.md#5-diagnostics-catalog).

## Diagnostics

### DW1000–DW1001 — the sculk family reaches nothing undeclared (`compiler::sculk`; error; exit 3)

Asked in the world block after the seating pass, over the assembled world (`emit::routes::prove_world`), after the rest rule (`DW0998`/`DW0999`, declared in `delvewright_dsl::blocks`) has judged every acting sculk cell of the assembled world and every block a runtime write lays. **Runtime writes are judged as every block a cell may hold at once**: a `fill-region`, `set-block` or `close-gate` at any root and depth, every laid write the region model carries (a way, a shortcut seal) and both phases of every timed gate (`sculk::runtime_writes`). A reach cell refuses if any block it may hold reads a signal, a cell above a sensor conducts if any block it may hold conducts, and a sensor stands wherever any write may lay one — every configuration of the derived-world sequence and every order of its unforced writes, so it can only refuse more.

| Code | Meaning |
|------|---------|
| `DW1000` | **A sculk sensor's redstone neighbourhood is not inert** (spec-0100 §3.4, §3.5). A sensor is a signal source on every face and a strong one upward [cited — `SculkSensorBlock.getSignal` / `getDirectSignal`], so its **reach** is its six face neighbours and, when the cell above it conducts (`blockshape::redstone_conductor`: the pinned jar's `isRedstoneConductor`, `always`/`never` per block, else the state's collision shape being the full block), that cell's five other neighbours. **First arm**: a reach cell holds a block that reads a signal (`blockshape::redstone_reader`: the block's, its block entity's or a nested class invokes a `SignalGetter` read — doors, trapdoors, fence gates, rails, lamps, bulbs, bells, big dripleaf, note blocks, dispensers, pistons, a calibrated sensor itself, …). The message names the sensor, the reach cell, how the power reaches it, the block, and whether it is there as placed or laid by which write. Nothing in the DSL consumes redstone (spec-0022), so the rule has no exception. **Second arm**: a calibrated sensor's input cell (`pos.relative(facing.getOpposite())`) holds a signal source or a conductor, which would set its frequency filter — the cell must stay free of both, so the sensor hears every vibration; a declared frequency needs a signal of exact strength this engine does not admit. The redstone facts are `crates/dsl/data/redstone-1.21.11.tsv`, measured from the pinned jar by `tools/maintenance/dump-redstone.py`. |
| `DW1001` | **A sculk catalyst can hear a death** (spec-0100 §3.7). A catalyst blooms on every living death within its listener range and, on one that drops experience, rewrites the blocks around it into sculk by the level's random [cited — `SculkCatalystBlockEntity$CatalystListener.handleGameEvent`], so the world the proofs judged would change mid-fight. It is admitted only where no body can ever be within range: the body cells are the closure of `World::body_moves` from every cell the campaign may put the party at (`lethal::put_at_roots`: the entry, every checkpoint, crossing, link and gather destination and loop landing, each snapped to its standable cell), united with the closure of `World::mob_moves` from every wave seat with the mob's own footprint — both over the world with every exclusion lifted (a killing volume is a place to die) and every barrier a hand opens standing open. Any body cell at integer `distSqr ≤ 64` to the catalyst's cell [cited — `EuclideanGameEventListenerRegistry`, radius 8] refuses, naming the catalyst, the nearest body cell, who stands there and the distance. |

**Binding.** Every build that assembles a world prints, before each verdict and zeroes included: `sculk rest: N acting sculk cell(s) of the assembled world and W runtime write(s) judged by the one rest rule`; `sculk: S sensor(s) (C calibrated), R reach cell(s) checked, K shrieker(s), T catalyst(s); W runtime write(s) judged beside the world as placed`; and `sculk: T catalyst(s), nearest body cell at distSqr D (cell); B body cell(s), M mob cell(s) examined` — or `no body cell to measure against` when it measured none. The waypoint export then prints `sculk walk: P of S sensor(s) predicted on L leg(s), Q of K shrieker(s); …` with the devices no leg predicts and each device a runtime write covers (never predicted), named with the write.
